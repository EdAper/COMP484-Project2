# Asset sources

| Asset | Source and use |
| --- | --- |
| Starting project | Course-provided `comp484-project2-main` starter ZIP. Its pet object, ready callback, button handlers, and stat update functions were extended. |
| `images/doge.png` | The user's uploaded `doge.png`, used unchanged as Dogey's image in Shibu Pal. It replaces the earlier pet image. |
| Inline icons | Simple SVG shapes written in the project source. No external icon library. |
| `images/paw.png` | PNG conversion of the project's paw favicon. The original design and transparent corners are preserved. |
| Scene, colors, layout, and animations | CSS in `style.css`. |
| Sounds | Short sine-wave notes synthesized by the browser through Web Audio. No downloaded sound files. |
| `vendor/jquery.min.js` | jQuery 3.6.1, OpenJS Foundation and other contributors. Bundled locally from the development environment's installed distribution. Copyright header retained. See `vendor/JQUERY-LICENSE.txt` and <https://jquery.org/license/>. |
| Fonts | System fonts: Segoe UI/Arial for interface text and Georgia/Times New Roman for headings. No external font downloads. |
